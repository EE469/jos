B.  There exists a PTE_U (User) bit, this bit when set to 1 lets the user environment access the kernel memory.
 In lab 2 we set that to 0 for any of the pages that have to do with the kernel addresses. This makes sure that the ring with the
 kernel memory stays unchanged and secure.

E.  Immediately after turning on paging EIP is low but then we jump to .relocated by setting cr3 to paging and getting the address in cr0.
 When we jump to .relocated we are switching the EIP from low to high virtual addresses that are above kernbase. This transition is necessary
 because the kernel expects to run at those high addresses. We also want the uder address space to be in the lower addresses so that it is 
 protected from the kernel.
